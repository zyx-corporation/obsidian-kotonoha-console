## RDE check

### Preserved Elements

Kotonoha remains spec-first, human-reviewed, and RDE-auditable.

### Authorized Transformations

The dogfood-proven minimal loop is hardened into a daily-use first UI release.

### Inferred Extensions

Engine labeling, sidecar validation, CLI parity, and Note I/O hardening become required v0.3 acceptance criteria.

### Unresolved Elements

v0.4 will revisit deeper integration: Git context export, partial apply UX, and sidecar/export correlation.

### Drift Risks

Experimental generation may be mistaken for stable behavior. Local and CLI audit paths may be mistaken for full RDE evaluation. Sidecars may be mistaken for complete SLS storage.

### Next Revision Policy

Revise this record only for v0.3.x corrective releases. v0.4 work should be tracked separately under the v0.4 epic.
